
# Healthcare Data Analysis Project

## Project Overview

This project focuses on analyzing healthcare data to identify useful insights related to patients, medical conditions, treatments, hospital operations, insurance types, and patient outcomes.

The project combines Python, SQL, Excel, and Power BI to clean, analyze, and visualize healthcare data through an interactive dashboard.

The main goal is to help healthcare management teams understand patient information, treatment outcomes, hospital performance, and operational patterns using data-driven insights.

---

## Business Objectives

- Analyze patient demographics and medical conditions
- Understand treatment and patient outcome patterns
- Compare insurance types and patient information
- Analyze hospital and regional performance
- Study admission types and length of stay
- Create an interactive healthcare dashboard
- Support data-driven decisions for healthcare management

---

## Dataset Information

The dataset contains **1,000 patient records** and **13 columns**.

### Main Columns

- Patient_ID
- Age
- Gender
- Medical_Condition
- Treatment
- Outcome
- Insurance_Type
- Income
- Region
- Smoking_Status
- Admission_Type
- Hospital_ID
- Length_of_Stay

The dataset was checked for missing values and duplicate records before analysis.

## Key Insights

- The dataset contains **1,000 patient records** across **13 columns**.
- The average patient age is approximately **45 years**.
- Patient information was analyzed based on medical condition, treatment, outcome, insurance type, and region.
- Admission types and length of stay can help healthcare teams understand operational requirements.
- Insurance and income-related information can support financial and patient-service analysis.
- The dashboard provides a consolidated view of patient demographics, medical information, and hospital-related metrics.
